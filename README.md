## Sobre

Sou estudante de **Tecnologia em Análise e Desenvolvimento de Sistemas no IFNMG** e desenvolvedor com foco em **back-end** e **desenvolvimento full stack** no ecossistema **TypeScript / Node.js**.

Trabalho no ciclo completo de uma aplicação: modelagem de dados, APIs REST, autenticação e autorização, regras de negócio, integrações com serviços externos, interface web e deploy.

## Áreas de atuação

- **APIs e back-end:** APIs REST com Fastify e Express, validação de dados com Zod, documentação com OpenAPI/Swagger
- **Autenticação e segurança:** JWT, OAuth e Better Auth, com controle de acesso por perfil
- **Banco de dados:** modelagem relacional com PostgreSQL e MySQL, usando Prisma e Drizzle ORM
- **Front-end e mobile:** React, Next.js e Vite na web; React Native com Expo no mobile
- **Integrações:** pagamentos com Stripe e APIs de IA
- **Infraestrutura:** Docker, CI/CD com GitHub Actions e deploy
